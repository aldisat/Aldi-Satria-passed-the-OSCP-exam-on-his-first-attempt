# Users
Analisa apakah ada user yang memiliki pola admin, seperti ADM dll, kalau enum list user lebih bagus pake `nxc smb --rid-brute`
```shell
rpcclient -U "danglingtree.htb/anderson.w%R3dT3am@Acc3ss#01" 10.129.27.241 -c "enumdomusers"
```
